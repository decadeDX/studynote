
# 1、Interger缓存
#Interger 
> 核心：`Integer` 是包装类，**`Integer.valueOf()` 会使用缓存池，-128 ~ 127 之间的整数复用对象**，超过范围会新建对象。

## 1. 源码（JDK 8）
```
public static Integer valueOf(int i) {
    if (i >= IntegerCache.low && i <= IntegerCache.high)
        return IntegerCache.cache[i + (-IntegerCache.low)];
    return new Integer(i);
}

// 静态内部类
private static class IntegerCache {
    static final int low = -128;
    static final int high;
    static final Integer cache[];

    static {
        // high 默认127，可以通过JVM参数修改
        high = 127;
        cache = new Integer[(high - low) + 1];
        int j = low;
        for(int k = 0; k < cache.length; k++)
            cache[k++] = new Integer(j++);
    }
    private IntegerCache() {}
}
```
### 缓存范围
- 默认：**`[-128 , 127]`**
- 上限 `high` 可以通过 JVM 启动参数修改：

```
-Djava.lang.Integer.IntegerCache.high=200
```
> 下限 `-128` **不能修改**。
## 2. 面试高频代码示例
```
public class Test {
    public static void main(String[] args) {
        Integer a1 = 100;
        Integer a2 = 100;
        System.out.println(a1 == a2); // true，缓存复用同一个对象

        Integer b1 = 200;
        Integer b2 = 200;
        System.out.println(b1 == b2); // false，超出缓存，new新对象

        Integer c1 = new Integer(100);
        Integer c2 = 100;
        System.out.println(c1 == c2); // false，new出来的不进缓存
    }
}
```

> 重点区分：

1. `Integer i = 100;` 自动装箱，底层调用 `Integer.valueOf(100)`，走缓存
2. `new Integer(100)` 永远新建对象，**不走缓存**

## 3. 什么时候会触发缓存？
✅触发缓存：
- `Integer.valueOf(int)` （自动装箱本质调用这个）

❌不触发缓存：
- `new Integer(int)` 构造方法，直接 new 对象
- 大于 127 / 小于‑128 的数值（没改 JVM 参数）

## 4. 重要坑点
1. **`==` 比较的是对象地址，`equals()` 才比较数值**

> 包装类判断相等，一律用 `equals()`，不要用 `==`。

```
Integer x = 130;
Integer y = 130;
System.out.println(x.equals(y)); // true，值相等
System.out.println(x == y);      // false，对象不同
```

2. 缓存是**静态常量数组**，类加载的时候就初始化完成，全局共享。
3. 只针对 `Integer`；`Long` 也有 LongCache，同样‑128~127；`Short、Byte` 也有缓存；**`Character` 缓存 0‑127**。
4. `Double/Float` **没有缓存池**。

## 5. 为什么要设计缓存？
- 高频使用的小整数，避免反复创建对象，节省堆内存，提升性能。

## 6. 扩展：修改缓存上限
启动 JVM 参数：
```
-Djava.lang.Integer.IntegerCache.high=500
```

此时 ‑128 ~500 全部复用缓存对象。

> 注意：这个参数只对 `Integer` 生效，**不建议生产随意修改**。
